# 教师导入工程题教程

教师只需要准备一个 ZIP 并在题库上传。平台会建立运行环境，用教师的参考提交试跑评分器，再显示是否可用于试卷。开始前请确认课程材料允许这样分发。

## 1. 整理文件

```text
project.json
public/
  README.md
  src/main.c
private/
  grade.py
  tests/...
  selfcheck/
    src/main.c
```

`public/` 放学生一开始看得到、可以修改的 UTF-8 文本。`private/` 放隐藏测试、资源与评分脚本。`private/selfcheck/` 放一份可用的参考提交，它的相对路径须对应已存在的公开文件；只放需要覆盖的文件即可。参考提交不会发给学生。

## 2. 写评分器

评分脚本可以调用你熟悉的编译器、测试框架和命令。平台提供三个环境变量：

| 变量 | 意义 |
| --- | --- |
| `PROJECT_SUBMISSION` | 本次提交的文件目录 |
| `PROJECT_PRIVATE` | 题包的隐藏文件目录 |
| `PROJECT_RESULT` | 评分结果 JSON 的目标路径 |

例如评分器最终写入：

```json
{
  "score": 72,
  "maxScore": 100,
  "needsReview": false,
  "items": [
    {"name": "公开检查", "score": 20, "maxScore": 20, "visible": true},
    {"name": "隐藏检查", "score": 52, "maxScore": 80, "visible": false}
  ]
}
```

分数必须在 0 到满分之间，`maxScore` 要与 `project.json` 一致。`visible: false` 的项目名称和反馈不会给学生。测试内容和评分公式由教师决定，平台只运行并读取结果。

## 3. 声明依赖

普通题优先在 `project.json` 写工具清单，不需要学习 Dockerfile：

```json
{
  "title": "修复一个多文件程序",
  "description": "请阅读 README.md，修改 src/main.c。",
  "language": "c",
  "difficulty": "medium",
  "environment": {
    "systemPackages": ["gcc", "make"],
    "pythonPackages": []
  },
  "graderCommand": ["python3", "private/grade.py"],
  "maxScore": 100,
  "selfCheckMinScore": 80
}
```

`systemPackages` 写 Debian 包名，例如 `gcc`、`make`；`pythonPackages` 写 pip 包名或固定版本，例如 `Django==4.2.5`。`language` 是展示标签；执行什么工具由依赖和评分器决定。建议将 `selfCheckMinScore` 设在参考提交预期得分附近，不要沿用默认的 1 分。Arch Lab 与不含浏览器测试的 SimpleBBS 均已用此入口验证。

若必须指定特殊系统或多步构建，可放 `private/Dockerfile`，必要构建文件放 `private/build/`，并从 `project.json` 删除 `environment`。镜像须包含 `/bin/sh` 和 `python3`，供平台 runner 使用。

## 4. 压缩并上传

ZIP 顶层直接是 `project.json`、`public/`、`private/`，不要再包一层总文件夹。在教师端打开“题库管理 → 导入工程题 ZIP”并选择文件。题库先显示“环境准备中”，完成后显示“环境自检通过”或失败信息。通过后可选入试卷并发布。

| 如果看到 | 先检查 |
| --- | --- |
| 缺少命令或依赖 | 包名、工具是否写全，`graderCommand` 是否为参数数组 |
| 参考提交分数过低 | 参考文件路径、测试预期、评分公式和最低分 |
| 没有评分结果 | 是否向 `PROJECT_RESULT` 写合法 JSON，满分是否一致 |
| ZIP 无法导入 | 顶层目录、UTF-8、路径与容量限制 |

偶发构建故障可点“重试自检”。题包本身有误时请修改 ZIP 并重新导入；当前界面不能直接修改已上传题包。详细协议和技术边界见[工程题上传与测评 v1](工程题上传与测评_v1.md)。真实示例的生成步骤见[Arch Lab 示例](../examples/archlab/README.md)。
