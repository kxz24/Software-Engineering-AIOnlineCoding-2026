## 当前状态

核心 10 页已完成；登录页拆成 **3 个静态登录态**（学生 / 教师 / 管理员），共 12 个页面。每页都是独立静态 HTML，画板 1440×900，CSS 全内联、无 JS、无外部字体/图片/依赖。

- 登录页为简洁居中单卡片；点角色只切换登录身份，点「登录」才进入对应端。
- 所有页面均已在 Edge 1440×900 下渲染检查。

## 墨刀导入步骤

1. 打开 [墨刀导入版/](墨刀导入版/) 文件夹，**不要用本地预览版**
2. 墨刀工作区 →「工具 / 更多」→「HTML 转原型 / HTML 转墨刀」
3. 先上传 `01-login` 的三个登录态（学生 / 教师 / 管理员），再按 `02 → 10` 逐页上传（单文件，不打包 zip，不加 Markdown 代码块）
4. 转换后保留默认的「AI 组件」
5. 选中组件，设置 **X=0、Y=0、W=1440、H=900**，页面/画板也设为 1440×900
6. 按 [页面跳转对照表.md](页面跳转对照表.md) 在按钮上盖透明热区，设置「点击 → 跳转页面」
7. 只对需要改文案、改数据的局部执行「转换为可编辑元素」，每转一组就检查一次

### 为什么本地预览版不能直接导入

本地预览版里的按钮是真实 `<a href="02-exam-list.html">` 链接，方便浏览器点着走；但墨刀里没有 `02-exam-list.html` 这个页面，预览时点击就会提示「没找到链接，可能被删除」。这不是页面被删了。

墨刀导入版已去掉所有 `href`，视觉完全一样，跳转全部由透明热区控制，不会再报这个错。

## 两条主路径

**学生**：01 登录（学生）→ 02 考试列表 → 03 环境自检 → 04 工作台 → 05 提交结果 → 06 过程报告

**教师**：01 登录（学生）→ 点「教师」tab → 01 教师登录 → 登录 → 07 考试管理 → 08 创建考试 → 09 命题与评测配置 → 10 监考中心

**管理员**：01 登录（学生）→ 点「管理员」tab → 01 管理员登录 → 登录 → 07 考试管理

## 备注

- 登录页有三个状态页，导入墨刀时三页都要导：
  - `01-login`（学生）：角色 tab 分别跳三个登录页，登录按钮 → 02
  - `01-login-teacher`（教师）：登录按钮 → 07
  - `01-login-admin`（管理员）：登录按钮 → 07
- 角色 tab 的热区在三个登录页之间互跳，不是直接跳到工作台。
- 申诉未单独成页。建议在 06 页「发起申诉」上做墨刀弹窗；需要独立页时可补 `11-appeal.html`。
- 06 的页内 tab、07 的「成绩分析」tab、10 的处置动作，首版均为静态示意；在墨刀里可做成组件状态或弹窗。
- 03 的「重新检测」、09 的「运行全部」、10 的「补时 / 终止」等属于运行时动作，原型里保留为按钮，不实现逻辑。
