# 页面跳转对照表（墨刀连线用）

> **本地预览**：打开 `本地预览版/index.html`，按钮自带链接，可以直接点着走完整原型。
> **墨刀导入**：用 `墨刀导入版/` 里的文件，所有 HTML `href` 已去掉，不会出现「没找到链接，可能被删除」的报错。
> 跳转全部按本表在墨刀里加热区：矩形工具 → 盖住按钮 → 填充/边框设为透明 → 右侧「交互」→ 点击 → 跳转页面。
> 建议先连登录三态和下面的学生 / 教师两条主路径，页内 tab 和次要操作最后补。

## 最小演示连线

如果时间有限，优先连这一条闭环：

`01-login → 02 → 03 → 04 → 05 → 06`

教师端再连：

`01-login → 点「教师」→ 01-login-teacher → 登录 → 07 → 08 → 09 → 07 → 10 → 06`

管理员端：

`01-login → 点「管理员」→ 01-login-admin → 登录 → 07`

这样已经覆盖「登录 → 考试 → 作答 → 判分 → 报告」和「命题 → 发布 → 监考」两条完整故事线。
